Contenedor web · Django + DRF

  • gunicorn: 2 procesos × 4 hilos · aplica migraciones al arrancar
  • API /api/v1: JWT 15 min + renovación 14 d · X-Device-Id
  • Ticket: firma public_id · type · overwrite · timestamp (vale 1 h)
  • Confirmación: verifica la firma → captura + tarea IA en 1 transacción
  • Salud /api/v1/health · tope 700 MB · 0,8 CPU

Regla de arquitectura

  • App y navegador solo hablan con Django por HTTPS; nunca con Supabase
  • En el campo, las cámaras solo hablan con el controlador
  • La foto no pasa por Django: solo firma y confirma
  • Secretos solo en el servidor, nunca en la app ni en Git
  • YOLO no es un servicio aparte; la sincronización no lo espera
